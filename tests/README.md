# Testes

`store.test.js` são testes automatizados (`node:test`) da camada de dados em
`frontend/js/store.js` — autenticação, permissões, correção automática e manual,
prazos, ficheiros, eventos e sincronização.

## Executar

```bash
npm test
```

Resultado esperado: 30 testes, todos aprovados. Relatório e casos de teste manuais
adicionais em `docs/08_testes.md` e `tests/test_cases.md`.

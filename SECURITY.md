# Segurança

Projeto académico, mas com boas práticas profissionais.

## Não publicar
- passwords
- tokens
- chaves privadas
- dados pessoais reais
- bases de dados reais

## Em caso de exposição
1. Revogar/substituir a credencial.
2. Informar o professor.
3. Corrigir o repositório.
4. Registar a melhoria preventiva.

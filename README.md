# Plataforma Assíncrona de Atividades Pedagógicas

## Visão geral
Plataforma escolar para criação, realização e avaliação de atividades pedagógicas assíncronas.

## Perfis principais
- Administrador
- Professor
- Aluno

## MVP
- Autenticação de utilizadores
- Perfis: administrador, professor e aluno
- Gestão de módulos/turmas
- Criação de atividades
- Questões de escolha múltipla e verdadeiro/falso
- Submissão de respostas
- Correção automática de questões objetivas
- Consulta de resultados e feedback

## Backlog inicial sugerido
- **US01 — Implementar autenticação:** Como utilizador, quero iniciar sessão para aceder às funcionalidades do meu perfil.
- **US02 — Gerir utilizadores:** Como administrador, quero criar e gerir utilizadores.
- **US03 — Gerir módulos:** Como administrador, quero criar módulos e associar professores e alunos.
- **US04 — Criar atividade:** Como professor, quero criar uma atividade para um módulo.
- **US05 — Adicionar perguntas:** Como professor, quero adicionar perguntas objetivas e abertas.
- **US06 — Submeter respostas:** Como aluno, quero responder e submeter uma atividade.
- **US07 — Correção automática:** Como professor, quero que perguntas objetivas sejam corrigidas automaticamente.
- **US08 — Consultar resultados:** Como aluno, quero consultar classificações e feedback.

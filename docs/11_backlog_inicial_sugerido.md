# 11 — Backlog Inicial Sugerido

> Ponto de partida fornecido no brief do cliente (secção 22). Serve de base para o backlog
> real e priorizado em [07_backlog.md](07_backlog.md) — não é a versão final.

## User Stories iniciais (do brief)

- **US01 — Implementar autenticação**
  Como utilizador, quero iniciar sessão para aceder às funcionalidades do meu perfil.

- **US02 — Gerir utilizadores**
  Como administrador, quero criar e gerir utilizadores.

- **US03 — Gerir módulos**
  Como administrador, quero criar módulos e associar professores e alunos.

- **US04 — Criar atividade**
  Como professor, quero criar uma atividade para um módulo.

- **US05 — Adicionar perguntas**
  Como professor, quero adicionar perguntas objetivas e abertas.

- **US06 — Submeter respostas**
  Como aluno, quero responder e submeter uma atividade.

- **US07 — Correção automática**
  Como professor, quero que perguntas objetivas sejam corrigidas automaticamente.

- **US08 — Consultar resultados**
  Como aluno, quero consultar classificações e feedback.

> Nota: o backlog não se limita a estas oito histórias — devem ser decompostas em tarefas
> técnicas e complementadas com as restantes necessidades identificadas em
> [01_analise_problema.md](01_analise_problema.md) e [02_requisitos.md](02_requisitos.md).
> Ver decomposição completa em [07_backlog.md](07_backlog.md).

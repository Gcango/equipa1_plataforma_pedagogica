# Guia de Contribuição

## Fluxo obrigatório
1. Selecionar/criar uma Issue.
2. Criar branch a partir de `main`.
3. Desenvolver.
4. Fazer commits pequenos e claros.
5. Push da branch.
6. Abrir Pull Request.
7. Solicitar Code Review.
8. Corrigir observações.
9. Fazer merge após aprovação.

## Branches
- `feature/nome`
- `fix/nome`
- `docs/nome`
- `test/nome`

## Commits
- `feat:` funcionalidade
- `fix:` correção
- `docs:` documentação
- `test:` testes
- `refactor:` refatoração
- `chore:` tarefa técnica

## Segurança
Nunca publicar passwords, tokens, chaves, ficheiros `.env` ou dados pessoais reais.
